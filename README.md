# AMERICIUM

A private Fabric mod for Minecraft Java Edition 26.3.

AMERICIUM replaces the new "Abandoned Camps" structure with American-style supercenter stores. Players pay with a custom AMERICIUM currency to buy villagers and netherite equipment.

## What it does

- The Abandoned Camps structure set (`minecraft:abandoned_camp`) is overridden: camps no longer generate. A superstore (`americium:store`) generates in the same 18 biomes with the same spacing.
- The store is 95 x 82 blocks: a parking lot with a few cars and lamp posts, a yellow walkway and a red carpet to a framed, canopied entrance with an ENTRANCE sign, a glass front, a blue sign (AMERICIUM and a yellow spark) and shelf aisles. It sits on a foundation, so the floor is level with the terrain.
- **Currency:** bronze coin (1), silver coin (10), gold coin (100). They are in the creative inventory under Ingredients.
- **Self service shelves:** every shelf is a barrel with the product floating above it and a price tag. Take what you want. About 100 products in 11 departments.
- **Pay when you leave:** when you enter the store area (naturally generated stores, or stores placed with `/place`, which use invisible zone markers) the mod remembers what you carry. At the exit gate (the entrance) it adds up everything you carry above that, takes the coins from your inventory and gives change. If you cannot pay, the goods are taken away again.
- **Stock clerks** walk through the aisles and refill the shelves next to them.
- **Shoppers and clerks** are villagers with AI: they walk around and make normal villager sounds. A function sends them back if they reach the door.
- **Trading villagers** (fixed in place): Pet Shop and Villager Market inside, and two Currency Exchange villagers outside the gate (emerald, diamond, gold ingot or netherite ingot into coins, and change making).
- Prices are placeholders. Change them in `tools/catalog.py` and regenerate (see below).

## Development status

The project builds with GitHub Actions. A server smoke test starts a real 26.3 dedicated server with the mod, places the store, reads the traders' offers and fails on errors. It has **not** been tested by a player in game yet, so the look of the building and the terrain fit are unchecked.

Ideas for later: a real coin texture, more trader stock, a tweaked spawn rate, different store sizes.

## Editing the store

The building, the shelf catalogue and the shop logic are generated by scripts:

```bash
python3 tools/gen_store.py 5023      # building, shelves, villagers (structure file)
python3 tools/gen_functions.py       # checkout and restock functions
```

`5023` is the world data version of Minecraft 26.3. Prices and products live in `tools/catalog.py`; run both scripts after changing it.

## Requirements

- Minecraft Java Edition 26.3
- Fabric Loader 0.19.5 or newer
- Fabric API
- Java 25

## Build

The GitHub Actions workflow builds the mod with Java 25 and uploads the JAR as the `americium-jar` artifact. Locally, use a Java 25 JDK and run:

```bash
gradle build
```

The resulting mod JAR will be in `build/libs/`.

## Note on names and logos

The store theme is inspired by a real retail brand. This project is for private use only and must not be published or distributed under that brand name or logo.
