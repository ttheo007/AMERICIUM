# AMERICIUM

A private Fabric mod for Minecraft Java Edition 26.3.

AMERICIUM replaces the new "Abandoned Camps" structure with American-style supercenter stores. Players pay with a custom AMERICIUM currency to buy villagers and netherite equipment.

## What it does

- The Abandoned Camps structure set (`minecraft:abandoned_camp`) is overridden: camps no longer generate. A superstore (`americium:store`) generates in the same 18 biomes with the same spacing.
- The store is 95 x 82 blocks: a parking lot with cars and lamp posts, a sidewalk, a glass front with a wide entrance, a blue sign (AMERICIUM and a yellow spark), checkout lanes, shelf aisles and 14 departments. It sits on a foundation, so the floor is level with the terrain.
- **Currency:** bronze coin (1), silver coin (10), gold coin (100). They are in the creative inventory under Ingredients.
- **Traders** (vanilla villager trading, so the server checks every purchase): Netherite Shop, Grocery, Clothing, Electronics, Pharmacy, Garden Center, Pet Shop, Sporting Goods, Auto Center, Books & Stationery, Home & Furniture, Jewelry, Villager Market (villager spawn egg) and Currency Exchange (emerald, diamond, gold ingot, netherite ingot into coins, and change making).
- **Cashiers** at the 8 checkout lanes make change between the coin types.
- **Shoppers:** about 44 villagers walk-in-place in the aisles. They are not silent, so they mumble like normal villagers.
- Prices are placeholders. Change them in `tools/gen_store.py` and regenerate (see below).

## Development status

The project builds with GitHub Actions. A server smoke test starts a real 26.3 dedicated server with the mod, places the store, reads the traders' offers and fails on errors. It has **not** been tested by a player in game yet, so the look of the building and the terrain fit are unchecked.

Ideas for later: a real coin texture, more trader stock, a tweaked spawn rate, different store sizes.

## Editing the store

The building and the traders are generated by a script:

```bash
python3 tools/gen_store.py 5023
```

`5023` is the world data version of Minecraft 26.3. The script writes `src/main/resources/data/americium/structure/store/main.nbt`.

## Requirements

- Minecraft Java Edition 26.3
- Fabric Loader 0.19.5 or newer
- Fabric API
- Java 25

## Build

The GitHub Actions workflow builds the mod with Java 25 and uploads the JAR as the `americium-jar` artifact. Locally, use a Java 25 JDK and run:

```bash
gradle build
```

The resulting mod JAR will be in `build/libs/`.

## Note on names and logos

The store theme is inspired by a real retail brand. This project is for private use only and must not be published or distributed under that brand name or logo.
